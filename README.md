# PIVE Possível com Cassiano Filho

Página de vendas da imersão PIVE Possível: O Plano do Laboratório Enxuto.

## Rotas

- `/a1`: dor e nova saída
- `/a2`: quebra de crença
- `/a3`: resultado e oportunidade
- `/obrigado`: orientações após a inscrição

As três páginas de vendas compartilham a mesma estrutura, identidade visual, oferta e conteúdo. Somente a hero muda entre as versões.

## Desenvolvimento local

1. Instale as dependências com `npm install`.
2. Inicie a prévia com `npm run dev`.
3. Abra `http://localhost:3000/a1`.

## Compilação

- `npm run build`: compilação para a infraestrutura Sites.
- `npm run build:vercel`: compilação de produção para a Vercel.

## Pendências de operação

Antes da abertura das inscrições, forneça o checkout, a data e o horário da aula, o link do grupo oficial, o canal de suporte e as condições finais exibidas no checkout.
